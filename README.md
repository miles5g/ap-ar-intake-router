# AP/AR Intake Router (synthetic demo)

**Portfolio demo** — multi-entity AP/AR intake → classify → route. All data is fake.

## What it shows

1. Ingest synthetic invoices / remittance lines for several fictional entities
2. Classify (AP vs AR, entity, urgency, exception type)
3. Route to a queue with a reason code

## Hard rules

- **Synthetic data only** — no real firm names, client names, or portfolio figures
- Recruiter-safe recreation of an ops automation pattern, not production software
